# Onur Ergüt

Computer engineering student at Yildiz Technical University. I build websites,
mobile apps and tools for the Mac.

## Published work

**[conv3rt](https://github.com/onurergut/conv3rt)** — native macOS image
converter in Swift and SwiftUI. Reads 60+ formats, writes 19 out of the box and
21 with the optional JPEG XL and AVIF encoders. Its Lossless mode blocks a
conversion with a plain-English reason when the target format cannot preserve
the image, instead of silently degrading it. MIT-licensed, signed and notarized
releases; **0.6.1** is the current version. Start with the [latest
release](https://github.com/onurergut/conv3rt/releases/latest).

**[Onur's Orchestration](https://github.com/onurergut/Onurs_Orchestration)** —
self-hosted Python service that runs a task through planning, implementation,
pytest, a bandit scan, review and a documentation update, checking a per-project
budget at every stage. Early prototype.
