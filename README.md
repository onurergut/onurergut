Computer engineering student at Yildiz Technical University. I build websites,

## Published work

**[conv3rt](https://github.com/onurergut/conv3rt)** — native macOS image
converter in Swift and SwiftUI. Reads 60+ formats, writes 19 out of the box and
21 with the optional JPEG XL and AVIF encoders. Its Lossless mode blocks a
conversion with a plain-English reason when the target format cannot preserve
the image, instead of silently degrading it. MIT-licensed, signed and notarized
releases; **0.6.1** is the current version. Start with the [latest
release](https://github.com/onurergut/conv3rt/releases/latest).

**[sw33p](https://github.com/onurergut/sw33p)** — native macOS cleaner for old
developer projects and build caches. Finds `node_modules`, Rust `target/`,
Python virtualenvs and `__pycache__`, Gradle and Xcode build output, and
package-manager caches, but lists a folder only when a project marker proves
what it is; app bundles and symlinked targets are refused. Sizes are allocated
sizes, and everything goes to the Trash unless permanent deletion is confirmed
separately. MIT-licensed, signed and notarized releases; **0.1.0** is the
current version. Start with the [latest
release](https://github.com/onurergut/sw33p/releases/latest).

**[scrib3](https://github.com/onurergut/scrib3)** — native macOS app that turns
video and audio into timed SRT, VTT, or TXT subtitles. Speech recognition runs
on-device through Apple's engine or WhisperKit, so recordings stay on the Mac;
cues are reviewed and edited next to a player before export, and the first use
of a language downloads its model once. MIT-licensed, signed and notarized
releases; **0.1.0** is the current version and needs macOS 26. Start with the
[latest release](https://github.com/onurergut/scrib3/releases/latest).

**[Onur's Orchestration](https://github.com/onurergut/Onurs_Orchestration)** —
self-hosted Python service that runs a task through planning, implementation,
pytest, a bandit scan, review and a documentation update, checking a per-project
budget at every stage. Early prototype.
